## Goal
The Lego set the DM builds maps from (D7): floors, walls, doors, stairs, pillars, props, per
biome, at the bible's scale (16 voxels per 5-ft tile, walls 32), exported to Unity prefabs that
snap to the grid and carry gameplay metadata. First biome: **dungeon** (POC + first campaign).

## Pipeline
```
tools/vox_write.py      Codex: tiny library, numpy voxel array + master palette -> .vox (VOX 150: SIZE, XYZI, RGBA)
assets-src/voxels/dungeon/<tile>.vox     Codex: source of truth, editable in MagicaVoxel later
assets-src/voxels/kit.json               Codex: one entry per tile (schema below)
tools/vox_check.py      Fable (done): contract validator; Codex runs it until PASS
tools/vox_to_obj.py     Codex: .vox -> .obj (+ .mtl) with greedy meshing, 1 voxel = 1/16 unit, Y-up,
                        origin at the tile's floor center; UVs address a 16x16 palette atlas PNG so URP/Lit
                        needs no vertex-color shader. Emissive indices go to a second material slot.
assets-src/voxels/obj/                   generated; tracked (small)
Assets/Dungine/Editor/VoxelKitImporter.cs   Fable: reads kit.json + obj -> prefab per tile with VoxelTile
                        (metadata) + MeshCollider; materials: KitPalette (Lit, atlas) and KitEmissive (Lit, emission on)
Assets/Dungine/Kit/Dungeon/*.prefab      generated by the importer (menu Dungine > Kit > Import)
```
Palette rule: `.vox` files are saved with the master palette in the RGBA chunk (index 1 = first
master color); voxel color indices are master indices. `vox_check.py` rejects anything else.

## kit.json schema (one entry per tile)
```json
{ "version": 1, "biome": "dungeon", "voxels_per_tile": 16,
  "tiles": {
    "floor_stone": { "file": "dungeon/floor_stone.vox", "category": "floor", "footprint": [1, 1],
      "height_tiles": 1, "blocks_move": false, "blocks_sight": false, "cover": 0, "elevation_half": 0,
      "difficult": false, "emissive": [], "biome": "dungeon", "mode": "both", "variant_of": null }
  } }
```
Fields: `category` floor|wall|door|stairs|platform|pillar|prop|light; `footprint` in tiles (w, d);
`height_tiles` max height; `cover` 0|1|2|3 = none/half/three-quarters/full; `elevation_half`
the elevation change in half-tiles a creature gets standing on it; `emissive` list of master
palette indices that glow; `mode` day|night|both; `variant_of` the base tile for worn variants.

## Dungeon tile list v1 (Codex produces exactly these)
| Category | Tiles (id) | Notes |
|---|---|---|
| floor | `floor_stone`, `floor_stone_worn_a/b/c`, `floor_stone_drain`, `floor_dirt`, `floor_water_shallow` | 1x1x(2 voxels thick + 1 detail layer); water = difficult, palette `water_*` |
| wall | `wall_block`, `wall_block_cracked`, `wall_block_mossy`, `wall_arrowslit`, `wall_sconce` | 1x1x2 tiles (16x16x32); sconce has `emissive_orange` voxels + `emissive` entry; blocks move+sight, cover 3 |
| door | `door_frame_open`, `door_closed`, `archway` | 1x1x2; frame/arch: no block; closed: blocks both |
| stairs | `stairs_half_up`, `platform_half`, `ledge_edge` | rises 8 voxels; `elevation_half` 1 |
| pillar | `pillar_round`, `pillar_broken` | 1x1x2.5 (40 voxels); cover 2 |
| prop | `table`, `chair`, `barrel`, `crate`, `chest_closed`, `chest_open`, `bookshelf`, `altar`, `sarcophagus`, `bones_pile`, `rubble`, `statue_knight` | footprint 1x1 unless noted (table 2x1, bookshelf 1x1x2, sarcophagus 2x1); props block move, cover 1 (2 for bookshelf/sarcophagus/statue), never sight unless >= 2 tiles tall |
| light | `brazier`, `torch_standing`, `candle_cluster` | `emissive_orange` voxels; `emissive` entries; cover 0 |

Style (bible §4): night-mode stone = `neutral_2/3` base with `night_purple_1/2` shadow voxels;
wood = `earth_wood` ramp; metal = `metal`; one accent per prop max; every tile has at least
one "grit" detail (chipped corner, moss patch, crack). No gradients: 3 tones per material. Top
faces of floors carry the detail layer; walls have a 1-voxel-deep relief (mortar lines every
4 voxels) so lighting reads on flat faces.

## Fable's part (after Codex delivers)
1. `VoxelKitImporter.cs`: reads `kit.json`, imports each OBJ, builds a prefab with `VoxelTile`

3. `GridMap` reads `VoxelTile` metadata (blocks, cover, elevation) instead of the wall list;
   this is also the contract Plan 12's editor writes.
